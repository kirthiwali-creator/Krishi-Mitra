# Krishi Mitra

A multilingual MERN web application that helps farmers sell their crops directly to buyers online, with no middlemen.

## Features
- Farmer and buyer registration and login
- Farmer dashboard to add, update and manage crop details
- Marketplace where buyers can browse crops and view crop details
- Buyer dashboard
- Mandi information page
- Available in **Kannada, English and Hindi**

## Tech Stack
- **Frontend:** React.js (Vite)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## How to Run
1. Clone the repo: `git clone https://github.com/kirthiwali-creator/Krishi-Mitra.git`
2. Server: `cd server`, then `npm install`, then create a `.env` file (see `.env.example` if present) and run `npm start`
3. Client: `cd client`, then `npm install`, then `npm run dev`
4. Open `http://localhost:5173`
